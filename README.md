Ce projet a pour objectif de réaliser une application permettant de récupérer des données JSON depuis une API et de les afficher a l'aide d'un FutureBuilder

Tant que l'utilisateur n'entre aucune donnée, aucune recherche ne sera réalisées.

dans le cas ou l'utilisateur commence ça recherche, le future builder affichera un maximum de 20 cartes obtenues depuis l'API réparties dans 2 collones
